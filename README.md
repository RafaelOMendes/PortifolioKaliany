# PortifolioKaliany
Portifólio para o trabalho de IHC 7º semestre ciência da computação

## 🚀 Como rodar o projeto

Este é um projeto estático com HTML, CSS e JavaScript puro — não requer instalação de dependências.

### Opção 1: Abrir direto no navegador

1. Clone o repositório:
   ```bash
   git clone https://github.com/RafaelOMendes/PortifolioKaliany.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd PortifolioKaliany
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador.

### Opção 2: Live Server (VS Code) — recomendado

1. Instale a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code.
2. Abra a pasta do projeto no VS Code.
3. Clique com o botão direito no `index.html` e selecione **"Open with Live Server"**.
4. O projeto abrirá automaticamente em `http://127.0.0.1:5500`.
